Release Notes

Changes to the Leeward Staff Portal, newest first.

Version 1

October 31, 2026 · First release notes

New

  • Bid Invites — invite approved vendors to bid from inside a project, save invites as drafts and finish them later, with automatic reminder emails.
  • Vendor Portal — vendors can sign in, see the projects they were awarded, and download each project’s COI template. A gold Portal Member pill shows which vendors have an active login.
  • Merge vendors — when approving a vendor application, merge it into an existing vendor instead of creating a duplicate.
  • Manage Projects for vendors — add a vendor to projects straight from the vendor page and request a COI by email.
  • Project scopes now show on the vendor detail page.
  • W-9 exemptions — mark a vendor W-9 exempt; SSN/FID and W-9 requirements adjust to match.
  • Project invoices — new Accounting page, invoice capture from your phone, hardware-store invoices (store + description instead of a vendor), and a per-project edit/delete setting.
  • Project photos — camera button on a project’s Overview on phones.
  • Install the app — add the portal to your phone’s home screen, with a step-by-step iPhone guide and a "Get the app" banner on the Dashboard.
  • Change Password in the bell menu, next to Sign out.
  • In-portal file preview for documents, instead of opening a new tab.
  • Form Settings per project on the Incident Report page, including project-specific BC/VPO Word templates.

Improved

  • Phone layout across the portal: bottom tab bar (customizable), a "More" sheet, notification panel, and a menu button on project pages.
  • COIs: the expiration date is what counts now; the PDF is only requested once a vendor is awarded a job, and each awarded project keeps its own COI.
  • Notifications page redesigned.
  • Project members popup rebuilt on Project Overview.
  • Files table on project pages: full width, scrolls sideways with a visible scrollbar.
  • Report Bug moved to the version line in the sidebar footer.
  • Vercel Web Analytics added to every page.

Fixed

  • "Remember this device" now works, and phones / the home-screen app no longer sign you out on reopen or after idling.
  • Project switcher dropdown no longer covers the sidebar collapse arrow.
  • Incident Report form: field widths, toolbar dropdown, and mobile layout (no more iOS zoom on focus).
  • Form Settings no longer fail for projects that didn’t have a settings row yet.
  • Legacy forms without a signature are filed into the correct "Without Signature" folder.
  • VPO numbering fix.
  • Bid invite project list loads even on older databases without project codes.
  • Sign out from the bell menu on My Tasks.
  • Invoices: existing Project Files sources are kept when the invoice source was added.
