Bids guide

Everything about bidding lives on the project's Bids tab: send a package, compare the prices that come back, and award each cost code to the vendor you pick.

How it works 1. New bid package 2. What vendors do 3. Compare 4. Award 5. QuickBooks Terms Questions

How it works

  1. New bid packageSay what you need priced and who should price it. Two steps.
  2. Vendors bidThey get an email and enter one price per building for each cost code.
  3. ComparePrices side by side. The lowest on each line is picked for you.
  4. AwardKeep the picks or change them, then confirm once. One package can go to several vendors.

1. New bid package

Click + New bid package on the Bids tab. The first time, you'll set up the project's buildings: each building type, how many of them, and which site-wide sections the project has (Site Work, Hardscape & Landscape, Amenities). Change them any time with Edit next to the buildings line.

Step 1: What

  • Package name, like Concrete or Framing.
  • Cost codes: type a number or name and press Enter. Add as many as the trade covers.
  • Price it for: all buildings are checked. Uncheck any the package doesn't cover.
  • Bids due: date and time.
  • More options (only if you need them): scope, plans from Project Files, walkthrough, questions due, your contact info, and reminders. Your contact info is remembered for next time.

Step 2: Who

Vendors who priced these cost codes before are already checked. Uncheck anyone you don't want, or find more by trade or name. Only approved vendors can be invited; others show what they're missing (address, W-9, COI, tags). Click Send, or Save draft to finish later.

2. What vendors do

Each vendor gets an email with a View Invite & Bid button. In the vendor portal they type one price per building for each cost code they want to bid (blank means they skip it) and attach their proposal. Reminders go out on their own if you left them on. Vendors never see each other's prices.

3. Compare

Click a package to open it. Each vendor is a column; each cost code is a row, grouped by building type. Prices are per building; the totals row multiplies by the number of buildings.

  • The lowest price on each line is shaded and picked as the Winner.
  • Change any winner to split the package, e.g. Foundations to one vendor and Termite to another.
  • Click a budget to change it. The bar under the table shows your picks against the budget.
  • A bid came in by email or phone? Use + Add a bid.
  • Remind waiting nudges everyone who hasn't answered.

4. Award

Click Award picks. You'll see each winner with what they won and their total. If you negotiated a lower number, type it as the contract amount. Choose whether to email the winners (they're also asked for their COI) and the vendors who weren't picked, then confirm.

Each winner gets one contract for what they won. Generate it from the project's Accounts page. If the project has no COI template yet, you'll be asked to post one first.

5. QuickBooks

Until the portal connects to QuickBooks Desktop, use Export for QuickBooks on the Bids tab. It downloads two files:

  • An IIF file with this project as a job and every awarded vendor. In QuickBooks Desktop: File › Utilities › Import › IIF Files. Tax IDs aren't included; add them in QuickBooks.
  • An Excel file with budgets by cost code and building, and each winner's contract amount.

The data stays in the portal, so you can export again any time.

Terms

Bid package
One trade you're asking vendors to price, with its cost codes and due date.
Building type
A group of identical buildings. Vendors price one building; the portal multiplies.
Site-wide section
Site Work, Hardscape & Landscape or Amenities. Priced once for the whole site.
Cost code
The number and name for a line of work, like 3002 Foundations - Turn-Key. Same list as the workbook.
Winner
The vendor picked for one cost code on one building type.
Contract amount
What a winner gets for everything they won: their prices × buildings, or the negotiated amount you typed.
