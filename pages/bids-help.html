How bidding works

← Back to Bids

You send a bid package, vendors send back prices, and you pick who gets the work. It all happens on the project's Bids tab.

1Send a bid package

A bid package is one trade you want priced, like Concrete or Framing. Each cost code becomes its own package when you click Send all on the Bids page (see above). Here's what goes into one.

First time on this project? You'll set up the buildings before anything else: each building type, how many there are, and whether there's Site Work, Hardscape or Amenities. It takes a minute, and you can change it later with Edit on the buildings line.

Step 1: What you need priced

  • Give it a name, like Concrete.
  • Add the cost codes. Start typing a number or a name and hit Enter to add it. The list is the numbered Trade tags on the Vendors page, so a new code is added there, under More Actions › Manage Tags.
  • All the buildings are checked. Uncheck any this trade isn't doing.
  • Pick the date and time bids are due.

Scope, plans, a walkthrough, your contact info and reminders are tucked under More options. You don't have to touch them, but attaching the plans saves you a lot of phone calls.

Step 2: Who should bid

Vendors tagged with these cost codes, and anyone who's priced them for us before, are already checked. Uncheck who you don't want, or search by trade or name to add more. When it looks right, click Send. If you're not ready, Save draft and come back to it.

Only approved vendors can be invited

If a vendor is grayed out, the list tells you what they're missing: address, tax ID, W-9, a current COI or trade tags. Fix it on their vendor page and they'll show up as approved.

0Before you invite

The first time you open Bids on a project, Theo walks you through two things the Invite Sheet needs:

  • The buildings: each building type and how many there are. Budgets and prices are per building, so this has to come first.
  • The COI template: a sample COI with the coverage this job needs. Award emails ask vendors for their COI, so it has to be posted.

Then click Open the Invite Sheet. After that, Bids opens straight to the sheet.

Need Manage Bid Invites

Only people with that permission can set up buildings and post the COI template. If you can't, ask them to finish it.

★The Bids page

The Bids tab is one sheet with a row for every cost code. The vendors tagged with that code on the Vendors page are already listed on each row.

  • Vendors: check who should bid. Three per code is the goal; you'll see a warning with fewer. + Add vendor adds someone who isn't tagged.
  • Budget: type the budget for one building of each type (site sections are for the whole site). It saves as you type.
  • Details: opens the scope of work, the plans to attach, the due date, walkthrough, contact, and a preview of the email each vendor gets.
  • Hide the codes this job doesn't need. They're hidden for this project only; Show hidden codes brings them back.

Each row says Ready or what it still needs. When every row still showing is ready, Send all lights up. One click emails every vendor, and each cost code becomes its own bid package. Your work is saved as you go, so you can fill it in over a few days.

Set it once at the bottom

The bar at the bottom sets the due date and contact for every row. Change them in a row's Details only when that code is different.

Grayed-out vendors can't be invited

They're tagged for the code but aren't approved yet, or have no contact with an email. Finish their vendor record and they'll be checkable.

2What vendors do

Each vendor gets an email with a View Invite & Bid button. They type one price per building for each cost code, attach their proposal and submit. If they skip a line, that just means they're not bidding it.

They can't see anyone else's prices. If they haven't answered, the portal reminds them for you, and everyone gets a nudge the day before bids are due.

3Compare the bids

Open a package and you'll see every vendor side by side, grouped by building type, with your budget in the second column.

  • The cheapest price on each line is shaded, and that vendor is picked as the winner.
  • Want a different vendor on a line? Change the Winner dropdown. That's how you split a package, like Foundations to GBS and Termite to Reaves.
  • Click any budget to change it.
  • The bar under the table adds up your picks and shows how you're doing against budget.
  • "Partial" under a vendor's total means they didn't price every line. They can still win the lines they did price.
Prices are per building

When you add a bid that came in by email or phone (+ Add a bid), type the price for one building. The portal multiplies it by the number of buildings. If you type the total, it'll be counted three times on a three-building type.

4Award the work

Click Award picks. You'll see each winner, what they're getting and their total. If you talked someone down, type the new number in Negotiated contract amount. Then choose who gets an email and confirm.

Double-check before you award

The emails go out as soon as you confirm, and there's no undo button on the page. Winners are told they got the job and asked for their COI. Everyone else is told they weren't picked. Uncheck the emails if you're not ready to tell people yet.

The project needs a COI template posted before you can award, since the email asks winners for their COI. If it's missing, the popup will ask you to add one.

Each winner gets one contract for everything they won. Make it from the project's Accounts page.

5Get it into QuickBooks

We don't have a direct connection to QuickBooks Desktop yet. Until we do, click Export for QuickBooks on the Bids tab and you'll get two files:

  • An IIF file with the project as a job and every vendor you've awarded. In QuickBooks, go to File › Utilities › Import › IIF Files. Tax IDs are left out on purpose, so add those in QuickBooks.
  • An Excel file with the budgets by cost code and building, plus each winner's contract amount.
Back up QuickBooks before importing

An IIF import can't be undone in QuickBooks. Make a backup of the company file first, just in case something comes in wrong.

?Questions

Where did Bid Invites and Bid Leveling go?They're one tab now, called Bids. Old links and bookmarks still land in the right place.
We added a building. Does everyone have to re-bid?No. Update the count in Edit buildings and every total changes with it.
The project is just one building, like a church.Add one building type (call it Church), set Buildings to 1, and leave Units blank. Units, GBSF and Leasable SF are all optional. Vendors then price that one building, and nothing gets multiplied.
Can I remove a building type?Yes, but any bids and budgets on it are deleted with it. You'll get a warning first.
Some older packages only show one total per vendor.Those were sent before cost codes were added. They still work: pick the winner and award like normal, they just can't be split.
I can't see the Bids tab.Ask IT to turn on Send Bid Invites or Manage Bid Invites for your workgroup. You need Manage Bid Invites to award.
