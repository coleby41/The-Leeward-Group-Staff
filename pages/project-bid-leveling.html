Set up the buildings first

Bid Leveling needs each building type on this project (how many buildings, units and square feet) and which site-wide sections it has. It takes a minute and you can change it any time.

Click a line to see every bid, set the budget and a negotiation target, and award. Best bid compares vendor prices only; the estimate is in the line for reference.

Set up buildings

Bid Leveling uses this to split bids by building type and multiply totals by the number of buildings. You can change it any time.

Building types

One row for each kind of building. Buildings of the same type share one bid sheet.

Site-wide sections

Priced once for the whole site, not per building. Turn off any this project doesn't have.

Bids are per building, so changing the number of buildings updates every total right away; nobody has to re-bid.
