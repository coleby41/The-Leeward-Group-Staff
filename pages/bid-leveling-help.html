Bid Leveling guide

How bids work in the portal, from setting up the buildings to awarding a vendor. It replaces the bid workbook: same idea, but the math is done for you and vendors send their prices in directly.

How it works

  1. Set up buildingsBuilding types, how many of each, units and square footage.
  2. Invite vendorsPick the cost codes, the buildings they cover, and the approved vendors.
  3. Vendors send pricesOne price per building for each cost code, in the vendor portal.
  4. CompareBid Leveling shows the best bid on every line against the budget.
  5. Negotiate and awardSet a target, then award the vendor's package.
  6. Contract and budgetThe award starts the contract with the right amount.

1. Set up buildings

The first time anyone opens Bid Leveling on a project, it asks for the buildings. To change them later, click Edit buildings.

Add one row for each building type, meaning buildings that are built the same way and share one bid sheet:

Name
What you call it, like "Pool House" or "24 Unit 1BR & 2BR".
Buildings
How many of this type are being built. Every total for the type is multiplied by this.
Building #s
Which buildings they are on the site plan, like 3, 4, 5.
Units / bldg
Apartments in one building. Used for $ per unit. Use 0 for a building with no units.
GBSF / bldg
Gross building square feet for one building. Used for $ per SF.
Leasable SF
Rentable square feet for one building.

Then leave on the site-wide sections this project has: Site Work, Hardscape & Landscape and Amenities. These are priced once for the whole site, not per building.

Good to know: bids are per building, so if the number of buildings changes later, just edit it. Every total updates and nobody has to re-bid.

2. Invite vendors

  1. Click + Invite vendors on Bid Leveling (or Vendors › More Actions › Generate A Invite Bid).
  2. Name the package, then under What vendors price pick its cost codes (for example 3001 Termite Treatment and 3002 Foundations) and the building types and sections it covers.
  3. Pick the vendors. Only Approved vendors can be invited.
  4. Set the due date and walkthrough, attach the plans, and send. You can save a draft and finish later.

Vendors get an email with a View Invite & Bid button. Reminders go out on their own before the due date. An invite with no cost codes picked works the old way: the vendor sends one total.

3. What vendors do

Vendors keep it simple. In the vendor portal they:

  • Choose Bidding or Not bidding.
  • Enter one price per building for each cost code and building type in the package. No breakdown. The portal multiplies by the number of buildings.
  • Add exclusions if they have any, attach their proposal PDF, and submit.

They can change their bid until the due date. Their prices show up on Bid Leveling as soon as they submit. Vendors never see each other's prices.

4. Compare bids

Bid Leveling has a tab for each building type and site-wide section, plus Summary. Each line shows:

Budget
What you planned to spend on this line, per building.
Best bid
The lowest vendor price and who sent it. After an award, the awarded vendor's price.
vs budget
Best bid minus budget. Orange means it's over budget.
Bids
How many prices are in, and how many invited vendors haven't answered yet.

Use Needs award to see only what's left. To set a budget before any bids come in, use + Add line. If a vendor sends a price by email or phone, open the line and click + Add bid.

5. Negotiate and award

Click a line to see every bid, with each vendor's exclusions and proposal PDF.

  1. Set the budget (and the estimate, if you have one).
  2. If you're negotiating, enter the reduction asked. The target bid, $ per unit and $ per SF update as you type. Click Save budget & notes.
  3. Click Award on the vendor you want.

Awards are per invite package, the same as on Bid Invites: awarding a vendor awards them everything they priced in that package. Their contract amount is their total after your reductions. You then confirm on the Bid Invites page, which sends the award email and asks for their COI.

6. Summary and export

The Summary tab adds everything up by cost code across all building types and site-wide sections, like the workbook's "Bid Summary by Cost Code".

Export to Excel gives you a workbook-style copy any time: one sheet per building type or section, plus the summary.

Terms

Building type
A group of identical buildings that share one bid sheet.
Site-wide section
Site Work, Hardscape & Landscape or Amenities. Priced once for the whole site.
Cost code
The number and name for a line of work, like 3002 Foundations - Turn-Key. Same list as the workbook.
GBSF
Gross building square feet.
Leasable SF
Rentable square feet.
Target bid
The vendor's price minus the reduction you asked for. The workbook called these "Negotiation targets".
Contract amount
The awarded vendor's total after reductions: each price × its number of buildings.

Questions

A vendor sent their price by email. How do I add it?Open the line and click + Add bid. Pick the package and the vendor, and type the price per building.
We added a building. Do vendors need to re-bid?No. Change the number of buildings in Edit buildings and every total updates.
Can vendors see other vendors' prices?No. Each vendor only sees their own bid.
Can I still get the Excel workbook?Yes. Export to Excel gives you the same layout as the workbook, with today's numbers.
Does the estimate count as the lowest bid?No. Best bid only compares vendor prices. The estimate is kept on the line for reference.
I don't see Bid Leveling.It uses the same access as Bid Invites. Ask IT to turn on Manage Bid Invites for your workgroup.
