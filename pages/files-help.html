Project files

← Back to Project Files

Every document for a job lives in its Project Files, sorted into the same numbered folders on every project. Plans, permits, contracts, invoices and photos all end up here.

1Find a file

Open a project and click Project Files. The folders are numbered the same way on every job, from 01 Acquisition & Due Diligence to 11 Closeout. Open a folder to see its subfolders, then pick one to see the files.

  • List shows the folder tree with the files next to it. Folders shows big folder tiles instead.
  • The number next to each folder is how many files are in it.
  • Looking for something and don't know where it went? Use the magnifying glass at the top of the project sidebar. It searches every file name on the project.

2Upload files

Open the subfolder the file belongs in and click + Upload File(s), or drag files from your computer straight onto the list. You can drop several at once.

Pick the right folder first

Files go into whichever subfolder is open. If you drop a file in the wrong place, it's easiest to delete it and upload it again in the right folder.

Some folders also show a + Fill … button. That opens a form (like a daily report); when it's submitted, the finished PDF files itself in that folder automatically.

3Open, rename and share

Click a file's name to preview it right in the portal. The ⋯ button on each row has the rest:

  • Preview and Download.
  • Rename the file.
  • Copy link gives you a link you can paste in an email. It stops working after a while, so send a fresh one if someone asks later.
  • Set as COI template (PDFs only) makes that file the COI template vendors see when they're awarded work.
  • Delete.
Make the list work for you

Drag a column header to move it, or drag its edge to make it wider. The portal remembers your layout.

4Files that come from elsewhere

Some files land here on their own: invoices from the Accounting page, signed contracts, bid proposals, approved incident reports, back charges, VPOs and phone photos. They show up in the right folder without anyone uploading them.

Invoices are managed on Accounting

If you try to rename or delete an invoice PDF here, the portal sends you to the Accounting page instead. That keeps the invoice and its file from getting out of sync.

5Delete a file

Choose Delete from the file's ⋯ menu. You'll be asked to type the file name and check a box before it goes.

Deleting is permanent

There's no trash or undo. Download a copy first if there's any chance you'll need it.

?Questions

Can I make my own folders?No. Every project uses the same folders so files are always in the same place, whoever filed them. If a folder is missing, ask IT.
Why can't I rename or delete some files?You can always change files you uploaded. Files someone else uploaded can only be changed by the project's admins and Project Manager, and invoices are always handled on the Accounting page.
Is there a size limit?Very large files can take a while to upload on a slow connection. Keep the page open until the upload finishes.
